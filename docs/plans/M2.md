## 2a — Player

### Files
```

  YouTubeSurface.tsx  # replaces the placeholder: band, player host, title, transport, "Paste link", "Queue", "Library"
  usePlayer.ts        # singleton YT.Player bound to the [data-player-rect] host div (never re-parented)
  queueStore.ts       # {items, index, repeat, shuffle} persisted in localStorage `jorgu:queue`

  PasteLinkSheet.tsx  # URL input + paste-from-clipboard button (text input fallback)

tests/unit/parseYouTubeUrl.test.ts · queueStore.test.ts

```

### Key behaviour
- **Singleton player.** `new YT.Player(hostDiv, { width: '100%', height: '100%', playerVars: { playsinline: 1, rel: 0, enablejsapi: 1, origin: location.origin }, host: 'https://www.youtube.com' })`.
  - The host div is positioned by the layout engine (pane / mini / full screen). When the rectangle changes, `player.setSize(w, h)` is called (a documented method). No CSS transforms or restyling of the iframe.
- **First play from a tap.** After that, `loadVideoById` drives the queue. On `onAutoplayBlocked` the app shows "Tap to play" outside the player.
- **Auto-advance only while visible.** On `ENDED`, the next item loads only if the YouTube surface is visible, the page is visible, and an IntersectionObserver reports > 50 % of the player on screen. Otherwise "Play next" waits for a tap.
- **Errors (§8.5).**
  - 101/150: skip, plus a toast "Skipped: the owner doesn't allow playback outside YouTube" with "Open in YouTube".
  - 100: skip, plus "Video removed or private".
  - 2/5: skip, plus "Couldn't play this video".
  - 153: stop, no retry loop, show "Player blocked: app identity missing", and `console.error` the detail.
- **Playback state is real.** `ui.youtube.playing` now comes from player state. The simulated toggle is removed. Mini player, floating bar, and control-column buttons drive the real player.
- **Playback speed.** Speed button in the transport row, mini-player handle, floating bar and control column. Tap cycles 1× → 1.5× → 2×. The rate is saved and re-applied on every new video. Unit test: cycle helper. E2E: rate becomes 2 and stays 2 after auto-advance.
- **Media keys [Verify].** `mediaSession.metadata` plus play/pause/next/previous handlers, and `keydown` for `MediaPlayPause` / `MediaTrackNext` / `MediaTrackPrevious`. Risk: the cross-origin iframe may own the media session. Tested and reported.
- **Toasts.** Positioned by `computeLayout` in the largest free area that doesn't intersect the player. Covered by the existing overlap tests.

## 2b — Account (needs your Google Cloud setup)

### Files
```
worker/
  index.ts            # router; JSON errors; Origin check on POST; security headers
  lib/session.ts      # AES-256-GCM (Web Crypto) cookie jg_session: httpOnly, Secure, SameSite=Lax, 180 d
  lib/google.ts       # auth URL (state + PKCE S256), code exchange, refresh, revoke, userinfo
  lib/yt.ts           # Data API calls, page-through, quotaExceeded / 401 mapping
  auth/  login · callback · logout · me
  yt/    subscriptions · feed · playlists · playlist-items · liked · search · videos
src/apps/youtube/account/
  api.ts              # fetch('/api/…', {credentials:'same-origin'}); 401 REAUTH → banner
  cache.ts            # idb-keyval with TTL; purge > 30 days; clearAll() on disconnect / invalid_grant
  libraryIndex.ts     # titles from playlists + liked; Intl.Segmenter('th') + substring match
  quota.ts            # searches used today (Pacific day) → "About N searches left today"
  LibrarySheet.tsx    # New from subscriptions · Playlists · Liked · Search (library first, then "Search YouTube")
  ConnectCard.tsx     # Connect / Connected: {email} / Disconnect + privacy consent line
public/privacy.html   # static privacy policy, English + Thai (§8.8)
tests/unit/worker/    # session crypto, cookie flags, refresh, invalid_grant → REAUTH, logout revoke, search rate limit (mocked fetch)
tests/e2e/account.spec.ts  # client flows with /api mocked via page.route; DevTools-visible storage has no tokens
```
Local dev: add `@cloudflare/vite-plugin` so `npm run dev` runs the Worker with `.dev.vars`.

### Acceptance → test
| Criterion | Test |
|---|---|

| No tokens visible in DevTools | E2E: localStorage, sessionStorage, IndexedDB, `document.cookie` contain no token-like strings. Unit: `/api/auth/me` never returns tokens. Cookie is httpOnly. |
